# Post-MVP 待办清单

> MVP 完成后（Phase 4 结束）的迭代计划。按优先级排序。

## 高优先级（MVP 验证后尽快补上）

| 功能 | 来源 Phase | 说明 | 预估工作量 |
|---|---|---|---|
| 简答题题型 | Phase 4 | LLM 评估简答题，需要设计评分标准（0-1）和稳定性测试 | 2-3 天 |
| 高级推荐算法 | Phase 3b | 基于用户行为的个性化推荐，语料库语义块复现匹配 | 1 周 |
| 熔断器模式 | Phase 4 | 连续 LLM 失败后自动降级，生产环境必备 | 1 天 |
| 动态语法聚光灯 | 产品方案 3.4.2 | 检测用户语法薄弱点，主动高亮标注 | 3-4 天 |

## 中优先级（功能完善）

| 功能 | 来源 | 说明 | 预估工作量 |
|---|---|---|---|
| Deep Dive Chat（与文章对话） | 产品方案 3.4.1 | 用户可以就文章内容向 AI 提问，侧边抽屉交互 | 1 周 |
| AI 助教个性化人设 | 产品方案 4.2 Pro 版 | 用户自定义 AI 交互风格，贯穿所有 AI 交互场景 | 1 周 |
| 每日统计预计算 | Phase 4 | user_daily_stats 表 + 夜间后台任务，优化仪表盘性能 | 1 天 |
| 口语模块（跟读/复述/表达） | 产品方案 3.6 | 与阅读内容关联的口语练习，需语音识别 | 2 周 |
| 浏览器插件（Web-to-App） | 产品方案 5.2 | Chrome/Safari 插件，一键导入外部英文内容 | 1 周 |

## 低优先级（扩展功能）

| 功能 | 来源 | 说明 |
|---|---|---|
| 轻社区功能 | 产品方案 3.8 | 分享、同好分组、轻互动 |
| 机构版/教师端 | 产品方案 4.2 | 班级管理、教师面板、作业系统 |
| 学术阅读模式 | 产品方案 5.3 | 开放获取论文、摘要、术语积累 |

| 心理能量监测 | 产品方案 5.4 | 基于行为信号推断用户认知负荷，调整推荐策略 |

## 从 MVP 简化的功能（后续升级）

| 功能 | MVP 版本 | 后续升级方向 |
|---|---|---|
| 问卷引导 | 单页 4 字段表单 | 多步向导 + 探针文章 + 动态校准 |
| 推荐算法 | 标签匹配难度 | 语义块复现匹配 + 梯度复现 + 主题关联 |
| 理解题 | 选择题 + 判断题 | 加简答题 + LLM 评估 |
| 通知推送 | 无 | 每日文章推送 + 个性化文案 + A/B 测试 |
