# 异步（async/await）

## 一句话解释

`async` = "这个操作要等一会儿，等的时候你可以先干别的"
`await` = "我要等这个操作完成，先让别人去忙"

## 为什么 Web 服务器需要异步

假设你的服务器只有一个工作人员（单线程）：

**同步方式**：
```
用户A: 帮我查数据库 → 等待 2 秒 → 拿到结果
用户B: （排队等着）
用户C: （排队等着）
```
查数据库的 2 秒里，工作人员什么都没干，就在等。

**异步方式**：
```
用户A: 帮我查数据库 → 工作人员发出查询，不等结果，先处理用户B
用户B: 帮我查数据库 → 工作人员发出查询，不等结果，先处理用户C
用户C: 帮我查数据库 → 工作人员发出查询
（数据库返回了）→ 工作人员分别把结果给 A、B、C
```
同样 3 个请求，同步要 6 秒，异步只要 2 秒。

## 代码里怎么写

```python
# 普通（同步）函数
def get_data():
    result = db.query("SELECT 1")   # 卡在这里等
    return result

# 异步函数 — 加 async
async def get_data():
    result = await db.execute(text("SELECT 1"))  # 发出请求，不卡住
    return result
```

**规则**：
- `async def` 定义异步函数
- 异步操作前面加 `await`
- 调用异步函数时也要加 `await`

## 我们项目里哪里用了异步

| 地方 | 为什么需要异步 |
|---|---|
| 数据库查询 | 查询要等 PostgreSQL 响应 |
| Redis 操作 | 要等 Redis 响应 |
| LLM 调用 | AI 生成文章要等 5-30 秒 |
| HTTP 请求 | 要等网络响应 |

都是"要等"的操作，所以用异步。不涉及等待的操作（比如纯数学计算）不需要异步。
